# Politique de sécurité

## Versions supportées

CinéLog est en développement actif. Seule la dernière version publiée sur
la branche `main` est maintenue.

## Signaler une vulnérabilité

Si tu découvres une faille de sécurité, merci de **ne pas** ouvrir une
issue publique. Contacte directement bloop.myds.me@gmail.com avec :

- Une description du problème
- Les étapes pour le reproduire
- L'impact potentiel

Un retour sera fait dans les meilleurs délais. Toutes les données de
l'application étant stockées localement sur l'appareil (AsyncStorage, pas
de backend ni de compte utilisateur), la surface d'attaque principale
concerne le code de l'application elle-même et ses dépendances.
